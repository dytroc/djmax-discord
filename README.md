# djmax-discord
> V-ARCHIVE에 올라온 데이터를 Discord 위젯 형태로 셋팅할 수 있게 도와주는 앱

## 사용법
### 위젯 생성하기
1. [공식 디스코드 개발자 포탈](https://discord.com/developers/applications)에 들어갑니다.
  - 위젯을 추가하고 싶은 계정에 로그인하셔야합니다.
2. 개발자 도구를 킵니다. (`F12` / `Ctrl + Shift + I`)
3. 상단 탭 중에 `콘솔 (Console)`에 들어갑니다.
4. [해당 코드](https://gist.github.com/dytroc/c39645319e2b5681241c0c2286b165ca)를 복사하고 실행합니다.
5. 콘솔에 뜨는 지시에 따라주시면 됩니다.
6. __프로그램에 사용될 설정이 자동으로 복사되기 때문에, 해당 내용을 어딘가에 저장해놓으세요__

### 위젯 데이터 갱신하기
1. 프로그램을 설치하지 않았다면, OS에 맞게끔 [설치](https://github.com/dytroc/djmax-discord/releases)합니다.
2. 프로그램을 실행합니다.
3. `위젯 생성하기`의 6번 항목에서 복사한 내용을 좌측 `콘피그` 하단의 텍스트 입력에 넣습니다.
4. 우측도 맞게끔 작성합니다.
5. `데이터 구하기` 버튼을 누른 뒤, `데이터 업로드` 버튼을 누릅니다.
